## Правила обработки (после скачивания)
1. Файлы — в `raw/sources/<код>/` (иммутабельный слой, имя: `<дата>_<описание>.pdf`).
2. Запись в `log.md`: `## [дата] ingest | <вещество> | <источник>`.
3. LLM анализирует: дозы/PHI/REI → обновление карточки (`dosage_normalized`, `phi_mrl.PHI_days`/`REI_hours`), снятие `insufficient_data`, задача в task_queue → [x].
4. Для каждой строки здесь — обновить статус: ⬜ → 🔄 анализируется → ✅ добавлено.

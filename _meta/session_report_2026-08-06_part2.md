## 6. Замечания для аудитора (что проверять)

1. **Renormalize-шум:** коммит `9620cf6` содержит 36 000+ EOL-изменений блобов (CRLF→LF
   в хранилище, рабочая копия остаётся CRLF) — это разовый эффект `.gitattributes`;
   реальные правки: 11 карточек + 4 скрипта/дока (см. `--ignore-space-at-eol`).
2. **Баннер черновиков** («⚠️ Черновик из CSV…») остаётся у 254 unverified-карточек — осознанно:
   это маркер невалидированности в Obsidian; если аудит сочтёт баннеры запрещёнными и для
   черновиков — отдельная массовая правка (вопрос открыт).
3. **Проверка миграции — только smoke-уровень:** факты карточек перенесены вручную по
   источникам (не перевалидированы); аудитору: выборочно сверить PMID-строки мигрированных
   карточек с артефактами `raw/evidence/**/search_*.json`.
4. **GA3/MeJA/GB — «расширение вне CSV»** сохранено в notes (томат/огурец не в Target_Crops) —
   не считать валидацией CSV для этих культур.
5. **bootstrap автозапускает gen_taxonomy** — при поломке gen_taxonomy bootstrap упадёт с
   ненулевым кодом подпроцесса (check=False — ошибка только в выводе, не в exit code);
   кандидат на `check=True` при следующей итерации.
6. **Vault/raw/** (7 файлов пользователя) — gitignored, вне конвейера.

**Сделано:** `_meta/subagent_prompt_v1.5.md` — 8 блоков, JSON-схема v1.5 (source_type,

### Задача 2. OpenAlex backoff в L1
**Сделано:** retry 3 попытки с exponential backoff (1с/2с/4с); при недоступности OpenAlex API —
⚠️ WARNING в консоль (не блокирует конвейер), оркестратор помечает источник
`verification_method: manual_read_pending` и перепроверяет. NO_TITLE (work без title) — остаётся
блокирующей ошибкой (ID существует, но не подтверждён).

### Задача 3. Ограничение label ≤20%
**Сделано:** L1 считает долю `source_type=label` на культуру; >20% → ошибка (заменить label на
верифицируемые идентификаторы).

## 6. Замечания для аудитора

1. **`verification_method: manual_read_pending`** — введён как пометка для OpenAlex-недоступности,
   но его нет в enum VERIF_METHODS L1. Решение: это пометка оркестратора в карточке/артефакте
   (не в source отчёта), L1 к нему не привязан. При необходимости добавить в enum v1.6.
2. **OpenAlex WARNING не блокирует** — ослабление верификации при недоступности API. Компромисс
   принят по ревью; NO_TITLE остаётся блокирующим (ID существует — значит, проверяемо).
3. **Промпт v1.5** — проверить на первом пакете следующей сессии: сабагенты должны генерировать
   contract_version 1.5 сразу.
4. **label ≤20%** — порог эвристический; на практике этикетки препаратов (PHI/REI) редки в claims.
5. **21/265 валидировано**, HIGH 28. Темп ~10/сессия.
